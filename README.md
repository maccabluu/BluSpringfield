# Blu Springfield

A BluStudio project for continuing a Springfield town-building game.

## Status

Initial setup only. No playable Android application is included yet.

## Development plan

1. Configure a self-hosted Springfield server.
2. Integrate a compatible Android client and authorized assets.
3. Test town saving, character jobs, currencies and quests.
4. Add new events and buildings.
5. Preserve save data and Android signing compatibility for updates.

## Starting point

Independent open-source Springfield server: https://github.com/al1sant0s/springfield (MIT licensed).

The server licence does not grant rights to third-party game art, characters, music or Android client software. Keep licensed content separate from public code until redistribution rights are established.
